# Фильтр автообъявлений

Страница для проверки объявлений о подержанных авто: считает ежемесячный платёж и проверяет машину по заданным критериям — коробка, привод, руль, тип двигателя, оценка аукциона, клиренс.

Открыть: https://blackrabbit1917.github.io/car-filter/

## Как устроено

- Один HTML-файл, без зависимостей и сборки. Работает офлайн — можно скачать и открыть двойным кликом.
- Критерии и стоп-факторы настраиваются на странице, каждый можно отключить.
- Список сохранённых машин и настройки хранятся в localStorage браузера.
- Перенос между устройствами — кнопки «Выгрузить в файл» и «Загрузить из файла».

## Что проверяет

Стоп-факторы: правый руль, вариатор, робот DSG/DCT, дизель, турбобензин, передний привод, люк, диски R19+, оценка аукциона R/RA, превышение потолка платежа.

Предупреждения: ввоз без ПТС, цена ниже рынка, низкий клиренс, большой пробег, возраст, отсутствие зимнего пакета, слабый мотор для трассы.
